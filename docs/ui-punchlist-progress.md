## 루프 계약 (매 주기 1항목)

1. 최상단 `[ ]` 항목 선택.
2. **확인**: 관련 컴포넌트/서비스를 읽어 현재 동작 파악. 이미 충족이면 `[x]` + 작업로그에 `확인: 이미 구현됨(근거 파일:라인)`.
3. **개선**: 미충족이면 구현. 기존 shadcn/ui·Tailwind OK 토큰·서비스 레이어 규칙 준수.
4. **검증**: `npx tsc --noEmit` EXIT 0 → `npm run build` EXIT 0.
5. **커밋**: **항목당 1커밋(원자적)** — 아침에 diff로 개별 검토·되돌리기 가능하게. 메시지 `feat:`/`fix:`/`style:` + 무엇을 했는지.
6. **로그**: 작업로그에 한 줄(확인 결과·한 일·검증).
7. ScheduleWakeup으로 다음 주기.
